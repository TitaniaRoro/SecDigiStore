🚀 INSTALLATION INSTRUCTIONS:
-----------------------------

1. UPLOAD TO CPANEL:
   - Login to your cPanel account
   - Go to File Manager
   - Navigate to public_html folder
   - Upload the entire verifiedbmwaba folder contents
   - OR extract verifiedbmwaba.tar.gz directly in public_html

2. CONFIGURE CONTACT FORM:
   - Open contact.html
   - Find: value="YOUR_WEB3FORMS_KEY"
   - Replace with your free API key from https://web3forms.com

3. UPDATE CONTACT INFO:
   - Edit contact.html with your actual:
     * Email address
     * WhatsApp number
     * Telegram username
   
4. ADD YOUR IMAGES:
   - Place product images in /images folder
   - Update image paths in HTML files

5. CUSTOMIZE PRODUCTS:
   - Edit product pages in /products folder
   - Update prices, descriptions, features as needed

🎨 THEME CUSTOMIZATION:
-----------------------
The website automatically detects visitor's system theme preference.
To customize colors, edit css/style.css:

For DARK theme - modify :root variables:
  --bg-primary, --text-primary, --neon-cyan, etc.

For LIGHT theme - modify [data-theme="light"] variables

🔧 TROUBLESHOOTING:
-------------------
Q: Dark mode not working?
A: Ensure JavaScript is enabled. Check browser console for errors.

Q: Contact form not sending?
A: Get a free API key from web3forms.com and update contact.html

Q: CSS not loading?
A: Verify file paths are correct. Clear browser cache.

Q: 404 errors on pages?
A: Ensure .htaccess is uploaded correctly. Check mod_rewrite is enabled.
